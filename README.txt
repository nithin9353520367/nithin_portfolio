NITHIN R PORTFOLIO

1. Install Node.js (LTS).
2. Open this folder in VS Code.
3. Open Terminal.
4. Run:
   npm install
   npm run dev

5. Open the local URL shown by Vite.

CUSTOMIZE:
- Edit src/data.js for your name, email, GitHub, LinkedIn, skills and projects.
- Put your resume at public/resume.pdf.
- Replace "#" project links with your GitHub/demo URLs.
- For a profile photo, add public/profile.jpg and we can add it to the hero section.

DEPLOY:
- Push the folder to GitHub.
- Import the repository into Vercel or Render.
- Build command: npm run build
- Output directory: dist
